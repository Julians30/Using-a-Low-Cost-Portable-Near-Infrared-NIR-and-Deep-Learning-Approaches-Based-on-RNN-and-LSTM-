# Figures

This directory will contain publication-ready figures generated by `NB08_PUBLICATION_FIGURES_TABLES.ipynb` from frozen outputs only.

Editorial rules:

- figure text in English
- no title embedded at the top of the figure
- captions stored separately from the image
- high-resolution PNG and TIFF outputs
- axis labels, units, legends and panel letters only inside figures

The final manuscript captions are maintained outside the image files so that journal production can format them independently.
