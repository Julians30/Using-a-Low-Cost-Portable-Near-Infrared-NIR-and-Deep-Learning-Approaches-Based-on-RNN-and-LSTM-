# Tables

This directory will contain publication tables derived from frozen NB06/NB07/NB08 outputs.

Final manuscript tables are intended to remain editable in Word. Repository CSV files preserve the exact underlying values used for typesetting.

Planned main tables:

1. Dataset, spectral acquisition and leakage-safe validation design
2. Prediction models and frozen modeling framework
3. OOF predictive performance
4. Egg-level statistical robustness and top-group post-hoc comparisons
5. Wavelength-order ablation
6. Predictive performance and computational applicability

Numerical rounding in the manuscript is editorial only; repository CSV values preserve higher precision where available.
